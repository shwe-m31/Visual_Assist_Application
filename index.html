Voice Commands

  • "Start detection" - Begin continuous detection
  • "Stop detection" - Pause detection
  • "What is around me" - Describe surroundings
  • "Who is nearby" - Detect people only
  • "What is ahead" - Describe objects in front
  • "Repeat" - Repeat last announcement
  • "Increase voice speed" - Make speech faster
  • "Decrease voice speed" - Make speech slower
